# CNS Final Project Backend

백엔드 코드 저장소입니다. 현재 협업 틀만 구성되어 있으며 애플리케이션 코드는 아직 없습니다.

## 시작하기
기술 스택과 런타임 버전을 결정한 뒤 프로젝트를 생성하고 아래 항목을 채웁니다.
- 필수 도구 및 버전: 미정
- 의존성 설치 명령: 미정
- 로컬 실행 명령: 미정
- 빌드 명령: 미정
- 테스트 명령: 미정
- 환경변수: 필요한 값은 `.env.example`에 이름만 공개하고 실제 값은 로컬 또는 배포 환경에 설정합니다.

## 협업
작업은 이슈 → 작업 브랜치 → PR 순서로 진행합니다. [개발 가이드](CONTRIBUTING.md)를 참고하세요.
